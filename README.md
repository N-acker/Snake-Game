# 🐍 Snake Game

A simple yet engaging **Snake Game** implemented in **Python**, offering a nostalgic experience reminiscent of the classic arcade game.

## 🎮 Features

- **Classic Gameplay**: Navigate the snake to consume apples, growing in length with each one eaten.
- **Score Tracking**: Earn points for each apple consumed, with the score increasing as the snake grows.
- **Game Over Conditions**: The game ends if the snake collides with the screen borders or its own body.

## 🕹️ Controls

- **Arrow Keys**:
  - **Up**: Move the snake upward.
  - **Down**: Move the snake downward.
  - **Left**: Move the snake to the left.
  - **Right**: Move the snake to the right.

## 🛠️ Technologies Used

- **Python**: The core programming language for game logic.
- **Tkinter**: Utilized for creating the game window and handling graphical user interface elements.
